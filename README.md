# Coloração de Grafos

Projeto acadêmico da disciplina de Teoria dos Grafos, desenvolvido em Java 17.

O objetivo é aplicar o algoritmo guloso, utilizando a coloração de grafos para organizar horários de provas e evitar conflitos entre disciplinas.

## Tecnologias

- Java 17
- Swing
- Algoritmo Guloso
- Heurística Welsh-Powell

## Como executar

É necessário ter o Java 17 ou superior instalado.

**1. Clone o repositório:**

```bash
git clone https://github.com/clebio0901/Coloracao-de-Grafos.git
```

**2. Acesse a pasta do projeto:**

```bash
cd Coloracao-de-Grafos
```

**3. Compile o código:**

```bash
javac Main.java
```

**4. Execute pelo terminal:**

```bash
java Main
```

**Para abrir a interface gráfica:**

```bash
java Main --gui
```
