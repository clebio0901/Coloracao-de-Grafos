# Coloração de Grafos

Projeto acadêmico da disciplina de Teoria dos Grafos, desenvolvido em Java 17.

O objetivo é aplicar o algoritmo guloso, utilizando a coloração de grafos para organizar horários de provas e evitar conflitos entre disciplinas.

## Tecnologias

- Java 17
- Swing
- Algoritmo Guloso
- Heurística Welsh-Powell
