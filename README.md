# COLORAPRO — Coloração de Grafos

Projeto acadêmico da disciplina de **Teoria dos Grafos**, desenvolvido em Java 17 no curso de Análise e Desenvolvimento de Sistemas do Instituto Federal da Paraíba (IFPB) — Campus Monteiro.

O objetivo é aplicar a **coloração de grafos**, utilizando o algoritmo guloso e a heurística **Welsh-Powell**, para organizar horários de provas e evitar conflitos entre disciplinas.

## Tecnologias

- Java 17
- Java Swing
- Algoritmo Guloso
- Heurística Welsh-Powell
- Programação Orientada a Objetos (POO)
